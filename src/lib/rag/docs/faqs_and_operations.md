# Whizzly Lab — FAQs, Security, Delivery & Engagement Operations

## 1. How Whizzly Lab Engagements Work
- **Phase 1: Architecture & Scope Audit (Week 0)**:
  - 15–30 min technical scoping call to define exact requirements, data flows, latency targets, and compliance needs.
  - Deliverable: Fixed-scope proposal with milestone breakdown and architecture blueprint.
- **Phase 2: Rapid Increment Delivery (Weeks 1–3)**:
  - We deliver working staging previews early. Clients receive weekly Loom walk-throughs and staging URLs.
- **Phase 3: Hardening & Automated Testing (Weeks 3–5)**:
  - Load testing, hallucination evaluations for AI pipelines, security audits, and edge caching.
- **Phase 4: Production Handover & Deployment**:
  - Full source code transfer, GitHub repository handover, Docker configurations, CI/CD pipeline setup, and 30-day post-launch support.

## 2. IP Ownership & Security
- **Who owns the code?**: You do. 100% intellectual property ownership is transferred to the client upon milestone completion.
- **Do you sign NDAs?**: Yes. We sign mutual Non-Disclosure Agreements before deep architectural discovery or code access.
- **Compliance Standards**: We follow SOC 2 Type II readiness patterns, zero-trust network boundaries, and HIPAA-compliant data encryption standards.
